# JeevanSetu Development Phases

## Phase 0 — Preparation
Install Node.js, Git, Antigravity and VS Code. Create GitHub repository, project structure, environment template and project docs.

## Phase 1 — Frontend foundation
Build landing page, auth screens, navigation, responsive layout and dashboard shells with dummy data.

## Phase 2 — Backend foundation
Create Express server, configuration, routing, validation, error handling, auth middleware and health endpoint.

## Phase 3 — Supabase
Create PostgreSQL schema, Auth, Storage, RLS, migrations and seed data.

## Phase 4 — Authentication
Implement registration, login, logout, sessions, roles and protected routes.

## Phase 5 — Patient core
Healthcare case, patient profile, documents and patient dashboard.

## Phase 6 — Verified resources
Hospitals, services, schemes, NGOs, search/filter and admin verification.

## Phase 7 — Referral coordination
Create referrals, status timeline, destination facility, notifications and follow-up.

## Phase 8 — AI recommendation
Backend AI integration, verified context retrieval, structured output, safety fallback, logging and recommendation UI.

## Phase 9 — AI assistant
Chat UI, controlled tools, resource search, referral status, patient context and safety guardrails.

## Phase 10 — PHC
PHC dashboard, medicine inventory, usage records, doctor check-in, patient visits and alerts.

## Phase 11 — Medicine forecasting
V1 deterministic stock calculation, V2 statistical forecasting, V3 ML only when sufficient data exists.

## Phase 12 — Service monitoring
Activity aggregation, anomaly detection, review flags and admin dashboard.

## Phase 13 — n8n
Low-stock alert, referral reminder, anomaly alert and feedback notification.

## Phase 14 — Accessibility and feedback
Web feedback, privacy-preserving feedback and IVR/local-language architecture.

## Phase 15 — Advanced modules
Document extraction, feedback classification, organ-donation information and future outbreak early warning.

## Phase 16 — Production hardening
Security review, RLS review, rate limiting, validation, logs, audit trails, monitoring, backups and performance checks.

## Phase 17 — Testing
Auth, authorization, privacy, referral, inventory, AI failures, API errors, automation, responsive UI and production tests.

## Phase 18 — Deployment
Vercel, Express hosting, Supabase, Python service if needed and n8n Cloud.

## Phase 19 — Competition/demo polish
Stable core flows, seeded demo data, polished UI, fast demo path, architecture diagram and clear problem/solution story.

## Phase 20 — Future scale
Only when needed: Redis, queues, background workers, Docker, service extraction, advanced ML and observability.
